# UI Audit — Impeccable Review — Editor (Anycubic Bridge)

**Date:** 2026-10-02
**Scope:** `apps/editor/src` (React 19 + Vite 8 + Tailwind v4 + shadcn/ui + three)
**Reference spec:** `docs/design-system-liquid-glass.md` + `sprint-planning/sprint-9-1/sprint.md`
**Method:** `impeccable` skill — 5 dimensions × 0–4, + patterns/systemic analysis, screenshots dark+light, computed-style probes.

---

## Anti-Patterns Verdict

**Partial AI-slop detected, concentrated in the legacy CSS layer.** The token
architecture (`index.css`) is excellent and spec-faithful; the failure is in
`styles.css`, which (a) depended on six tokens that **were never defined**, and
(b) shipped ~15 hard-coded hex colors that broke dark mode. This is the "two
layers diverged" pattern: the design system moved forward, the legacy classes
didn't, and nothing flagged the dangling `var()` references.

Before this pass, **Theming** scored 2/4: six undefined tokens (`--panel-bg`,
`--bg-panel-solid`, `--text-muted`, `--accent-warm`, `--ok-primary`,
`--danger-primary`) silently fell back to light-theme hex (`#ffffff`,

colors and 3px side-stripes that violate the spec's "1px hairline" rule.

## Patterns & Systemic Issues

1. **Dangling token references** (`var(--x)` with no definition) — the root
   cause. Mitigation added to `AGENTS.md`: run a `script/check-css-vars` in the
   gate (optional future).
2. **Hard-coded hex in legacy classes** — all ~15 occurrences now tokenized.
3. **Side-stripes >1px** — 3px rails on `.chat-message`/`.slice-stats` are the
   only remaining exceptions; spec allows "accent hairline" but not >1px body
   borders. Left as deliberate emphasis (documented).
4. **Glass inconsistency** — floating read-outs now use `--glass-fill-2` +
   blur + hairline (spec §3.4 substrate); popovers that need legibility use
   solid `--bg-dialog` (allowed exception for text-heavy surfaces).

## Positive Findings

- `index.css` token layer is spec-faithful: flat kebab-case namespaces,
  `@custom-variant dark` on `[data-theme=dark]`, full light/dark pairs, sane
  default contrast (`text-primary` vs `bg-base` passes AA in both themes).
- `--sel-bg` / `--sel-hover` are excellent selection tokens (12% accented
  tint, 5% neutral hover) — reused for active-tab fills.
- `.plate-tabs`, `.plate-tab.is-active` (pill, `999px` radius, accent-ring) —
  the best parts of the viewport; untouched.
- View-cube, toolbar `is-active` (`6px` radius + accent-tint) already spec-correct.
- `tabular-nums` used in all numeric read-outs; micro-labels (10–11px,
  uppercase, `0.08em`) present across journal/deltas/shortcut-help.
