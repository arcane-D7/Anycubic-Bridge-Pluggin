# S1 Parity Budget — declared before the run (S8-001)

**Status:** DECLARED (pre-run) — the numbers are fixed here; the comparator
measures actual deltas against them. Any revision after measurement requires a
journaled reason (never silent).

**Date declared:** 2026-09-28
**Sprint:** 8 (R2) — S8-001 (S1 spike: planar parity baseline)

## Method

Fixed 3-part planar corpus (`tests/fixtures/` — sanitizer-clean, deterministic):

| #   | mesh            | size (mm)    | note                     |
| --- | --------------- | ------------ | ------------------------ |
| 1   | `cube-20mm.stl` | 20 × 20 × 20 | plane-aligned cube       |
| 2   | `cylinder.stl`  | Φ20 × 25     | axis-aligned cylinder    |
| 3   | `bracket.stl`   | 60 × 30 × 8  | planar bracket (3 holes) |

Reference side: Anycubic Slicer Next CLI (`scripts/slicer-cli.mjs`, pinned
`AnycubicSlicerNext.exe`), standard process preset (`0.20mm Standard` @ Kobra
S1 0.4 nozzle). Candidate side: own planar core IR (S8-002/004) or its gcode
via the preprocessor (S8-005), same process profile (layer height 0.20 mm,
2 walls, 15% infill).

Both sides are normalized to the same summary shape (per-layer wall count,
infill volume %, bbox mm) by `scripts/compare-planar-runs.mjs`
(`analyzeGcode` / `analyzeIr`).

## Declared Budget

| metric               | budget            | rationale                                            |
| -------------------- | ----------------- | ---------------------------------------------------- |
| per-layer wall count | ±0 (exact)        | wall count is structural; candidate must match       |
| infill volume %      | ≤ 15 % relative   | infill pattern can differ; material volume budget    |
| bounding box         | ≤ 1.0 mm per axis | slicing must not move or scale geometry; the         |
|                      |                   | reference measures the outer wall BEAD CENTRE, which |
|                      |                   | sits ~0.45 mm inside the model surface per side, so  |
|                      |                   | up to ~0.9 mm off the model bbox is physical, not an |
|                      |                   | error; budget leaves margin for lift/spiral-up moves |

## Measurement

Reflects the deltas measured by running `pnpm run slices` (comparator on the
3-part corpus). See `s1-parity-results-*.md` (appended after the run).
